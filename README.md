# fakelock — CatCrypt (пранк-локер)

Полноэкранный **пранк** в стиле «видео с локером»: чёрный экран, маджентовый бокс,
консольные строки, часы, «ID компьютера», поле для кода разблокировки и всплывашка
«замечена попытка снять блокировку».

Это **не** вирус и **не** шифровальщик. Никакого шифрования, доступа к файлам, сети,
телеграма, автозапуска и требований денег внутри нет — только картинка и звук.
Выход есть всегда: **Ctrl+Q**.

![скриншот](assets/pink_art.png)

## Что происходит при запуске

1. Чёрный экран, затем консольные строки (`CatCrypt lock xd:3`, `system locked`) + котик.
2. Розовый экран с артом.
3. Локер: заголовок «Ваши файлы зашифрованы», текст, часы, поле кода.
4. Любой код + `Enter` → «код принят» → программа закрывается.
5. `Esc` / `Ctrl+W` → всплывашка «Замечена и остановлена попытка снять блокировку!».

## Управление

| Клавиша | Действие |
|---|---|
| `Enter` в поле кода | «разблокировать» (любой текст) |
| `Ctrl+Q` | аварийный выход |
| `Ctrl+M` | вкл/выкл звук |
| `Esc`, `Ctrl+W` | показать предупреждение |

## Запуск из исходников

Нужен Python 3.10+ и tkinter. Опционально: `pillow` (арт), `numpy` (синтез звуков).

```bash
python3 fakelock.py              # полный экран
python3 fakelock.py --windowed   # окно 1100x620, чтобы проверить
python3 fakelock.py --no-music   # без музыки
```

Звуки из видео лежат в `assets/sfx`, синтезированные (клики, бипы) собираются
автоматически во временную папку.

На Hyprland окно само уходит в настоящий fullscreen (через `hyprctl`), иначе
waybar остаётся сверху; на Windows — `-fullscreen` + страховка `overrideredirect`.

## Сборка .exe (Windows)

Собрать exe можно только на Windows (или в CI/Wine). Варианты:

* двойной клик по `build_exe.bat` (нужен Python с python.org);
* GitHub Actions: workflow `.github/workflows/build-exe.yml` собирает
  `fakelock.exe` и кладёт артефактом.

Готовый `fakelock.exe` лежит в разделе **Releases**.

PyInstaller-сборки иногда ругает Windows Defender — это ложное срабатывание
на упаковщик, не на код.

## Структура

```
fakelock.py          весь код (tkinter, без внешних зависимостей кроме pillow/numpy)
assets/cat.png       логотип на заставке
assets/pink_art.png  розовый экран
assets/sfx/*.wav     alarm / beep / music из видео
build_exe.bat        сборка exe на Windows
fakelock.spec        spec для PyInstaller
.github/workflows/   CI-сборка exe
```
